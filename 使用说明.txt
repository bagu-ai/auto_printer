标签自动打印工具 — 使用说明
================================

【运行环境】
· Windows 10 / 11
· 已安装 BarTender（Automation 或 Enterprise 版）
· 已连接标签打印机（东芝 B-EX4T1 或 ARGOX CP-2140M）
· 不需要安装 Python 或任何其他软件

【文件说明】
· 标签自动打印工具.exe — 主程序，双击运行
· 模板\ — 放 BarTender 模板（.btw）的文件夹，必须和 exe 在同一目录
· 映射配置和打印日志自动保存在：
    C:\Users\<你的用户名>\AppData\Roaming\标签自动打印工具\
  （重装或移动 exe 都不会丢配置）

【使用步骤】
1. 双击「标签自动打印工具.exe」（首次启动约需 10-20 秒解压，请耐心等待）
2. 把 Excel 清单（.xls / .xlsx）拖进窗口（或点“浏览…”）
   → 自动识别表头行和数据
   → 有多个工作表时可在「工作表」下拉框切换
   → 「送样数量」列如 “10g*3瓶” 自动作为每行默认打印张数（3 张）
   → 日期自动显示为 2026-01-03（不会带 00:00:00）
3. 选择标签模板（中文版 / 英文版）
   → 字段列表在后台读取，请稍等一两秒
4. 核对「字段映射」：每个模板字段取 Excel 哪一列（同名会自动选好），
   也可以选“固定文本”手动输入，或“留空”
5. 在左侧「数据工作台」点击任意一行，右侧「标签校样」自动刷新：
   → “适合窗口”：完整显示且不放大超过源图
   → “100%”：按原始像素核查字体和边缘
   → “− / +”：在 25%–400% 之间缩放
   → “独立查看”：打开大窗口专门核对标签
6. 数据工作台可搜索任意列；拖动中间分隔条可调整数据区和校样区宽度
7. 勾选要打印的行、调整每行张数；右上角和打印按钮实时显示总张数
8. 选打印机（默认用模板里保存的，你的选择会被记住）
9. 先点「试打当前行」核对一张实物，确认无误后点蓝色「打印 N 行 · N 张」
   → 打印前会自动预检：空值、重复编号、未映射字段都会提醒
   → “运行记录”默认收起，点击可展开；出现错误时会自动展开

【模板准备 — 一次性】
模板里需要自动填充的文本/条码，必须先在 BarTender 里起名字：
  双击对象 → 数据源 → “名称”一栏填上有意义的名字
  （如 发货新编号、客户香型、发货粒径）→ 保存模板
没起名字的对象不会出现在映射表里（按模板原样打印）。

【常见问题】
Q: 双击 exe 没反应 / 提示 BarTender 不可用
A: 确认本机装了 BarTender Automation/Enterprise 版，且能正常打开。
   弹窗里也可以选“干跑模式”先演示流程（不会真打印）。

Q: 字段映射表是空的
A: 模板里没有命名数据源，见上面【模板准备】；或模板读取还在进行，稍等片刻。

Q: 预检提示“某列有 N 行为空”
A: 该 Excel 列在这些行没有内容，打印出来对应位置是空白。
   确认无误可以继续；有问题就回去改 Excel 或调整映射。

Q: 打印出来的内容不对
A: 先在右侧「标签校样」用 100% 或独立查看核对，再「试打当前行」；
   不对就调整字段映射（映射会自动保存）。

Q: 打印中断了怎么办 / 想查打了哪些
A: 每次打印都有任务日志：
   %APPDATA%\标签自动打印工具\logs\ 里按时间命名的 .json 文件，
   记录了每一行的打印内容和成功/失败状态。

Q: 杀毒软件报毒
A: PyInstaller 打包的 exe 偶有误报，加白名单即可。
