Format.UseDatabase Property

Description

Sets or returns whether or not to use a connected database when printing.

Syntax

Format.UseDatabase = true|false

If true, this property will enable BarTender to print records from a database that is connected to the document.

Requirements

Version

BarTender 6.00 or higher

Edition

Automation, Enterprise

Remarks

The Format.UseDatabase property replaces the obsolete Format.UseInputDataFile property.

VB.NET Example

'Declare a BarTender application variable

Dim btApp As BarTender.Application

'Declare a BarTender document variable

Dim btFormat As BarTender.Format

'Create a new instance of BarTender

btApp = New BarTender.Application

'Set the BarTender application visible

btApp.Visible = True

'Open a BarTender document

btFormat = btApp.Formats.Open("c:\Format1.btw", False, "")

'Set the Use Database option

btFormat.UseDatabase = False

'Print the document

btFormat.PrintOut(False, False)

'End the BarTender process

btApp.Quit(BarTender.BtSaveOptions.btDoNotSaveChanges)

C# Example

// Declare a BarTender application variable

BarTender.Application btApp;

// Declare a BarTender document variable

BarTender.Format btFormat;

// Create a new instance of BarTender

btApp = new BarTender.Application();

// Set the BarTender application visible

btApp.Visible = true;

// Open a BarTender document

btFormat = btApp.Formats.Open("c:\\Format1.btw", false, "");

// Set the Use Database option

btFormat.UseDatabase = false;

// Print the document

btFormat.PrintOut(false, false);

// End the BarTender process

btApp.Quit(BarTender.BtSaveOptions.btDoNotSaveChanges);
