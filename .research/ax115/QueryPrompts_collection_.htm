QueryPrompts Collection Object

Description

Manages the list of query prompts defined for a BarTender document.

Requirements

Version

BarTender 6.00 or higher

Edition

Automation, Enterprise

Methods

Name

Description

GetQueryPrompt

Returns a reference to a specified QueryPrompt object.

Item

Returns a reference to a specified QueryPrompt object.

Properties

Name

Description

Count

Returns the number of query prompts.
