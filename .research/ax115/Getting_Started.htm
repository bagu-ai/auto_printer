Getting Started with ActiveX Automation

Use the BarTender ActiveX Automation interface to integrate the BarTender printing functions inside other Windows applications. You can access most of the BarTender data retrieval, data entry, and printing functionality by using a programming interface. When you do this, you can quickly modify and print labels or cards without interacting with the BarTender main user interface.

The following procedures describe how to create a Visual Studio project that uses the BarTender ActiveX Application Programming Interface (API).

To specify a project type in Visual Studio 2005 or later versions

  1. On the File menu, click New, and then click Project.

  2. In the Project types panel, under either the Visual C# or the Visual Basic node, click Windows.

  3. In the Templates panel, click Windows Application.

  4. Name the project, and then click OK.

To reference the BarTender ActiveX API

  1. Open the Project menu, and then click Add Reference.

  2. Click the COM tab.

  3. Scroll down to and click the BarTender reference so that it is selected.

  4. Click OK.

This procedure instructs the programming interface where to search for the BarTender ActiveX API. You can also now access all of the objects, methods, and properties in the BarTender ActiveX API.

After your application is created, you are ready to begin programming by using ActiveX Automation.
