PrintSetup Object

Description

Represents the printer and the print job configuration.

Requirements

Version

BarTender 7.50 or higher

Edition

Automation, Enterprise

Properties

Name

Description

AutoPrintAgain

Sets and returns the option to automatically print again.

Cache

Returns a reference to the Cache object.

IdenticalCopiesOfLabel

Sets and returns the number of copies to print.

LogPrintJob

Sets and returns the option to log the print job in the BarTender log file.

NumberSerializedLabels

Sets and returns the number of items to print in a serialization sequence.

Performance

Returns a reference to the Performance object.

Printer

Returns the name of the printer.

PrintMethod

Returns a reference to the PrintMethod object.

PrintToFile

Sets and returns the print-to-file option.

RefreshDatabases

Sets and returns the option to reload databases just before the job is printed.

StartingPosition

Sets and returns the starting position to use when printing if there are multiple rows and/or columns of labels on a page.

UseDatabase

Sets or returns the current setting of the document option to use an attached database for printing.
