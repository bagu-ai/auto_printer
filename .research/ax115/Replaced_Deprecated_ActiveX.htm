Replaced and Deprecated

Occasionally entire objects or one or more of their elements may be replaced to improve functionality of the ActiveX automation method. Replaced and deprecated elements are listed here to help you identify these elements and to direct you to the improved approach to the automation that you require.

Replaced

Element

Remarks

Database.ODBC Property

BarTender 2016 introduced new functionality to the Database object that eliminates the need for a separate ODBC object. While the ODBC object is still supported in BarTender 2016, you are encouraged to instead use the new properties of the Database object. It is possible that the ODBC object will be deprecated in a future BarTender version.
