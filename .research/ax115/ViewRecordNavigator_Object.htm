ViewRecordNavigator Object

Description

Supports browsing of database records in a template design.

Requirements

Version

BarTender 9.4 SR1 or higher

Edition

Automation, Enterprise

Properties

Name

Description

CurrentRecord

Sets and returns the current record number displayed on the template.

Enabled

Sets and returns whether the live database view is enabled.

IsConnected

Returns whether the record navigator is able to access the document's database.

LastRecord

Returns the last record number in the document's database.
