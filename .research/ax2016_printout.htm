Format.PrintOut Method

Description

Prints the BarTender document.

Syntax

Format.PrintOut(ShowStatusWindow, ShowPrintDialog)

Where

  • ShowStatusWindow, optional in VB.NET and required in C#, determines whether a prompt showing the status of the print job will be displayed.

  • ShowPrintDialog, optional in VB.NET and required in C#, determines whether the print dialog will be displayed.

Requirements

Version

BarTender 6.00 or higher

Edition

Automation, Enterprise Automation

Remarks

If ShowStatusWindow is true, then a prompt will display showing the status of the print job. If ShowPrintDialog is true, the print dialog will be shown. The PrintOut method returns void.

VB.NET Example

'Declare a BarTender application variable

Dim btApp As BarTender.Application

'Declare a BarTender document variable

Dim btFormat As BarTender.Format

'Create a new instance of BarTender

btApp = New BarTender.Application

'Open a BarTender document

btFormat = btApp.Formats.Open("c:\Format1.btw", False, "")

'Print the document

btFormat.PrintOut(False, False)

'End the BarTender process

btApp.Quit(BarTender.BtSaveOptions.btDoNotSaveChanges)

C# Example

// Declare a BarTender application variable

BarTender.Application btApp;

// Declare a BarTender document variable

BarTender.Format btFormat;

// Create a new instance of BarTender

btApp = new BarTender.Application();

// Open a BarTender document

btFormat = btApp.Formats.Open("c:\\Format1.btw", false, "");

// Print the document

btFormat.PrintOut(false, false);

// End the BarTender process

btApp.Quit(BarTender.BtSaveOptions.btDoNotSaveChanges);
